# STRG — Strategy Replayer, Visual Monitor & QLUA Mock Harness

Графический терминал и стенд тестирования торговых стратегий в стиле терминала QUIK на Python (PyQt6 / pyqtgraph) с исполнением чистых Lua-скриптов через `lupa` (Lua 5.5).

---

## 🎯 Основные возможности

1. **Исполнение оригинальных `.lua` файлов**:
   - Стратегии работают напрямую на языке Lua (например, `true_f_formock.lua`) без переписывания на Python.
   - Независимость логики: вы можете редактировать `.lua` руками в любом редакторе, а STRG на лету перезагружает стратегию по кнопке `[ 🔄 Обновить ]`.
   - Высокопроизводительный numpy-пайплайн: прогон 175 000 тиков за ~0.9 сек.

2. **Графика в точном стиле QUIK Dark**:
   - Строгий Win32-дизайн: 0px скругления, 1px рамки, шрифт Tahoma 11px, палитра `#111111`.
   - Тонкие контурные свечи (1px косметические фитили).
   - Точные временные метки (`HH:MM`) и ценовая шкала.

3. **Интерактивный Market Replayer (Плеер тиков)**:
   - Кнопки: `[ ⏹ В начало ]`, `[ ⏮ Шаг ]`, `[ ▶ Старт / ⏸ Пауза ]`, `[ ⏭ Шаг ]`.
   - Поддержка горячей клавиши `Пробел` для паузы/старта.
   - Слайдер-скруббер перемотки времени по всему дню.
   - Скорости воспроизведения: `1x`, `5x`, `25x`, `100x`, `MAX`.
   - Табло текущего времени (`HH:MM:SS`) и цены.
   - Динамическое дыхание последней свечи (Candle Morphing).

4. **Визуализация сигналов и уровней**:
   - Желтые пунктирные уровни фракталов с бейджами `Fractal <цена>` от точки появления до снятия.
   - Стрелки сделок со смещением: Buy (влево), Sell (вправо).
   - Цветовая дифференциация:
     - 🟢 Real Buy / 🔴 Real Sell
     - 🟡 Virt Buy / 🟣 Virt Sell
   - Номера попыток перезахода (`#1`, `#2`, `#3`, `#4`) у каждой стрелки.
   - Защитные линии Stop Loss (красный пунктир) и Take Profit (зеленый пунктир).

## 📁 Структура проекта

* `main.py` — точка входа приложения.
* `gui_window.py` — разметка окон, тулбаров, плеера и панели управления.
* `chart_canvas.py` — графический холст на pyqtgraph (свечи, уровни, сделки, SL/TP).
* `lua_runner.py` — быстрый модуль запуска Lua-стратегий через `lupa`.
* `tick_aggregator.py` — парсер тиковых данных и сборщик свечей (OHLCV).
* `theme.py` — палитра и стили QUIK Dark (0px borders).
* `run_strg.bat` — скрипт запуска через виртуальное окружение Python.
* `TODO_STRG.md` — дорожная карта разработки и этапы.
* `screenshots/` — референсы и снимки экранов интерфейса.
